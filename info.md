# qBittorrent Plus

Expanded Home Assistant integration for **qBittorrent** — Core parity plus transfer control, categories/tags, and optional active-torrent entities.

- Local WebUI polling via `qbittorrent-api`
- Instance sensors, alt-speed switch, speed-limit numbers, pause/resume-all buttons
- Services for add/pause/resume/delete/recheck/tags/categories/limits
- Hybrid mode: dynamic entities for active torrents only (configurable cap)
